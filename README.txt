ДУША, ПОКРЫТАЯ КРОВЬЮ — ГОТОВАЯ СБОРКА ДЛЯ GITHUB PAGES

1. Распакуйте ZIP.
2. Удалите старые версии файлов из корня репозитория или замените их.
3. Загрузите ВСЁ содержимое этой папки в корень ветки main.
4. Сохраняйте структуру папок:
   character-images/
   army-images/
5. В Settings → Pages укажите:
   Deploy from a branch → main → /(root)

Главные страницы:
index.html — главное меню
world.html — карта мира
characters.html — персонажи
emerdals.html — Эмердалы
empires.html — Империи и Королевства
codex.html — Кодексы

Главная страница не требует отдельного изображения. Городской фон и полёт орла созданы кодом.

Проверка завершена: все локальные ссылки из HTML ведут на существующие файлы.
